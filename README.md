# ⚡ Apex DeskFlow — Productivity Hub

A native Python desktop application designed for daily business ops tracking, financial logging (KES), task management, and automated reporting.

## 🚀 Key Features

* **📊 Live Operations Dashboard:** Overview metrics showing total ledger transactions, total recorded volume (KES), and task completion progress.
* **💰 Cash Ledger:** Log income and expenses with validation, currency formatting, and persistent storage.
* **📝 Task Manager:** Interactive task tracking with status updates (`Mark Completed`) and deletion.
* **⚡ Automated Summary Exporter:** Compiles ledger entries and task status into an exported text report file (`DeskFlow_Summary.txt`).
* **💾 Local Persistence:** All data automatically saves locally to `data.json`.

## 🛠️ Built With

* **Language:** Python 3
* **GUI Framework:** Tkinter / TTK
* **Data Storage:** JSON
